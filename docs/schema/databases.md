# Databases

All four databases live on one PostgreSQL server — the `pgvector-payflo` container (port 5432) locally, and the `postgres` StatefulSet on Kubernetes, where each database has its own user with privileges on it alone. Locally they are created by hand once ([setup](../local-development/setup.md#2-create-the-four-databases)); on Kubernetes an init script creates them.

| Service | Database | Tables | Entities |
|---|---|---|---|
| merchant-service | `payflo_merchant` | `merchant`, `app_user`, `api_key`, `customer`, `merchant_webhook_config` | `Merchant`, `AppUser`, `ApiKey`, `Customer`, `MerchantWebhookConfig` |
| payment-service | `payflo_payment` | `order_record`, `payment`, `payment_transition_log`, `refund`, `outbox_event` | `OrderRecord`, `Payment`, `PaymentTransitionLog`, `Refund`, `OutboxEvent` |
| vault-service | `payflo_vault` | `vault_card`, `card_token` | `VaultCard`, `CardToken` |
| operations-service | `payflo_operations` | `webhook_event`, `dlq_event`, `settlement`, `settlement_payment`, `outbox_event` | `WebhookEvent`, `DlqEvent`, `Settlement`, `SettlementPayment` (+ `SettlementPaymentId`), `OutboxEvent` |

That is 17 entity types plus one `@Embeddable` composite key.

## Identifiers

Every entity has a UUID `id` generated by JPA (`GenerationType.UUID`), except `SettlementPayment`, whose primary key is the pair (`settlement_id`, `payment_id`).

## Audit columns

Every entity extends `common-lib`'s `BaseEntity`, so every table also has `created_at`, `updated_at`, `created_by` and `updated_by`. The timestamps are filled by JPA auditing; the two `_by` columns hold the API key id, `merchant_id: <uuid>`, or `SYSTEM` for work done by a scheduler or consumer. The ER diagrams leave these four columns off each card.

## Money

An amount is always the `Money` embeddable: `amount_units`, an integer count of the currency's smallest unit (paise for INR), and `currency`, an ISO code. It is never a floating-point value, so arithmetic can't drift. An entity with several amounts overrides the column names — `settlement` has five pairs (`gross_amount_units` / `gross_amount_currency`, …).
